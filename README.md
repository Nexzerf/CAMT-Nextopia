# CAMT NEXTOPIA 🌆

เกมค้นหาตัวตนในมหานครแห่งอนาคต ปี 2099 ว่าเราเหมาะกับสาขาไหนใน
**วิทยาลัยศิลปะ สื่อ และเทคโนโลยี (CAMT) มหาวิทยาลัยเชียงใหม่**
จบเกมแล้วมี **วงล้อนำโชค** ลุ้นของรางวัล

## ลำดับการเล่น
1. **Intro**: ใส่ชื่อเล่น (ไม่บังคับ) แล้วกดเข้าเมือง
2. **Story**: AI "CAMI" เล่าเรื่องสั้น ๆ (แตะข้อความเพื่อข้ามได้)
3. **Quiz**: 6 คำถาม ใน 6 โซนของเมือง (ลำดับตัวเลือกสุ่มทุกครั้ง)
4. **Scan → Result**: บอกสาขาที่เหมาะ + persona + วิชาเด่น + อาชีพ + % ความเข้ากันกับทุกสาขา + จุดเด่น CAMT
5. **วงล้อรางวัล**

| เขตในเมือง | สาขา |
|---|---|
| CODE SPIRE | Software Engineering (SE) |
| NEXUS EXCHANGE | Modern Management and IT (MMIT) |
| PRISM STUDIO | Animation and Visual Effect (ANI) |
| ARCADE ARENA | Digital Game (DG) |
| SYNTH FORGE | Digital Industry Integration (DII) |

## เทคนิค
- HTML/CSS/JS ล้วน ไม่มี backend ไม่ต้อง build ใช้กับ **GitHub Pages / Vercel / Netlify** ได้เลย
  เป็นไฟล์ static คนเข้าพร้อมกันเยอะแค่ไหนก็ไม่มีเซิร์ฟเวอร์ล่ม
- เปิดดูในเครื่อง: `python3 -m http.server` แล้วเข้า `http://localhost:8000`
  (ห้ามเปิดไฟล์ตรง ๆ แบบ `file://` เพราะจะโหลด `config/prizes.json` ไม่ได้)

## 🎁 ของรางวัลและโอกาส
ตั้งค่าที่ `config/prizes.json` (`chance` = % ต่อการหมุน 1 ครั้ง)

| รางวัล | จำนวน | โอกาส | ประมาณ |
|---|---|---|---|
| คลิกเกอร์ 1 ปุ่ม | 5 | 1.00% | 1 ใน 100 คน |
| คลิกเกอร์ 3 ปุ่ม | 5 | 0.80% | 1 ใน 125 คน |
| กระเป๋า | 2 | 0.25% | 1 ใน 400 คน |
| แก้วน้ำ | 2 | 0.25% | 1 ใน 400 คน |
| ขอบคุณจ้า | — | 97.70% | |

ถ้ามีคนเล่น ~800 คน รางวัลจะทยอยออกจนหมดพอดี ถ้าคาดว่าคนเยอะกว่านี้ ให้ลด `chance` ลง

- ผลลัพธ์สุ่มจาก % จริง (ใช้ `crypto.getRandomValues`) ส่วนวงล้อเป็นแค่ภาพที่หมุนไปหยุดตรงช่องของผลลัพธ์
- ผู้ได้รางวัลจะได้ **รหัสรับรางวัล** เช่น `NX-BG-7K2QF` พร้อมนาฬิกาเดินสด (กันการแคปหน้าจอมาเคลม)
  สตาฟจดรหัสหรือดูจาก Staff Console ได้

### ระหว่างงาน เมื่อของหมด
- **แบบเล่นบนมือถือตัวเอง (สแกน QR)**: แก้ `config/prizes.json` บน GitHub ตั้ง `"enabled": false` ให้รางวัลที่หมด
  ทุกเครื่องจะโหลดค่าใหม่ทุกครั้งก่อนหมุน (GitHub Pages อาจหน่วง ~1 นาที)
  แต่ละมือถือหมุนได้ **1 ครั้ง** (จำไว้ในเครื่อง)
- **แบบตั้งแท็บเล็ตที่บูธ (Kiosk)**: เปิด Staff Console แล้วติ๊ก "โหมดบูธ"
  เครื่องจะนับสต็อกเองและตัดรางวัลที่หมดออกอัตโนมัติ, หมุนได้ 1 ครั้งต่อการเล่นจบ 1 รอบ

### Staff Console
แตะโลโก้ **CAMT NEXTOPIA** มุมซ้ายบน 5 ครั้ง (หรือเปิด `/#staff`) → PIN `2026`
(เปลี่ยน PIN ได้ที่ `ADMIN_PIN` ใน `js/app.js`)
- ปรับสต็อก/โอกาส/เปิด-ปิดรางวัล เฉพาะเครื่องนั้น
- เปิด/ปิดโหมดบูธ, ปลดล็อกการหมุน, รีเซ็ตยอดแจก
- ดูประวัติการหมุน + ดาวน์โหลด CSV

> หมายเหตุ: ไม่มี backend จึงนับสต็อกรวมข้ามหลายเครื่องไม่ได้ ถ้าเล่นบนมือถือหลายเครื่อง
> สต็อกจริงคุมโดยสตาฟที่บูธ + ปิดรางวัลใน `prizes.json` เมื่อของหมด

## โครงสร้างไฟล์
```
index.html          หน้าเว็บทั้งหมด
css/style.css       ธีมนีออนเมืองอนาคต
js/data.js          ข้อมูลสาขา + คำถาม (แก้คำถามได้ที่นี่)
js/city.js          ฉากเมืองอนาคตแบบเคลื่อนไหว (canvas)
js/wheel.js         วงล้อ + ระบบสุ่มรางวัล
js/app.js           ลำดับหน้าจอ, คิดคะแนน, Staff Console
config/prizes.json  ของรางวัล / จำนวน / โอกาส
```
