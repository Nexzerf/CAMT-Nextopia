# CAMT NEXTOPIA 🌆

เกมค้นหาตัวตนในมหานครแห่งอนาคต ปี 2099 ว่าเราเหมาะกับสาขาไหนใน
**วิทยาลัยศิลปะ สื่อ และเทคโนโลยี (CAMT) มหาวิทยาลัยเชียงใหม่**
จบเกมแล้วมี **วงล้อนำโชค** ลุ้นของรางวัล

## ลำดับการเล่น
1. **Intro**: เห็นเมืองพิกเซลพร้อมพลเมืองทุกคนที่เล่นไปแล้ว
2. **สร้างตัวละคร**: ชื่อเล่น + สีผิว ทรงผม สีผม เสื้อ ของแต่ง (มีปุ่มสุ่ม)
3. **ด่านเข้าเมือง** แล้วตอบ **6 คำถาม** (ตัวละครเดินไปตามเส้นทางทีละโซน)
4. **ผลลัพธ์**: สาขาที่ใช่ + persona + วิชา/อาชีพ, ตัวละครย้ายเข้าเขตของสาขานั้นในเมือง (ใส่เสื้อสีประจำเขต)
   - **แชร์ลงสตอรี่**: สร้างการ์ด 1080×1920 → มือถือเปิดแผ่นแชร์ (เลือก IG/FB Story), คอมดาวน์โหลด PNG
   - **ดูบ้านในเมือง**: ลากดูเมือง 5 เขต แตะคนเพื่อดูชื่อ ปุ่ม "ตัวฉัน" พากลับไปหาตัวเอง
   - **หมุนวงล้อรางวัล**

## เทคนิค
- หน้าเว็บเป็น HTML/CSS/JS ล้วน ไม่ต้อง build ใช้กับ **GitHub Pages / Vercel / Netlify** ได้เลย
- ระบบรางวัล + พลเมืองใช้ **Supabase** (project `Project2`, schema `nextopia`)
- เว็บเรียก API ผ่าน `/api/rpc/*` บนโดเมนเดียวกัน (`vercel.json` ส่งต่อให้ Supabase) เพื่อให้ใช้ได้แม้เครือข่ายบล็อก `*.supabase.co`
  ถ้ารันในเครื่องโดยไม่มี proxy จะสลับไปเรียก Supabase ตรงอัตโนมัติ
- ชื่อเล่นกรองคำไม่เหมาะสม (`nextopia.banned_words`) และสตาฟซ่อนตัวละครได้จาก Staff Console
- เปิดดูในเครื่อง: `python3 -m http.server` แล้วเข้า `http://localhost:8000`

## 🎁 ระบบของรางวัล (อัตโนมัติ ไม่ต้องแก้ config)
การสุ่มและการตัดสต็อกทำบน **เซิร์ฟเวอร์ Supabase** พร้อมกันในขั้นตอนเดียว ทุกเครื่องใช้สต็อกเดียวกัน
- ของชิ้นไหนหมด โอกาสได้ชิ้นนั้นเป็น 0% ทันทีทุกเครื่อง **ไม่มีทางแจกเกินจำนวนจริง** แม้คนกดพร้อมกัน
- มือถือ 1 เครื่อง หมุนได้ 1 ครั้ง (เซิร์ฟเวอร์จำไว้ ล้างแคชกลับมาก็จะเห็นผลเดิม)
- การสุ่มอยู่ฝั่งเซิร์ฟเวอร์ แก้โค้ดในเบราว์เซอร์เพื่อโกงไม่ได้
- ถ้าเน็ตหลุด หน้าจอจะบอกให้ลองกดใหม่ (ไม่เสียสิทธิ์)

| รางวัล | จำนวน | โอกาส | ประมาณ |
|---|---|---|---|
| คลิกเกอร์ 1 ปุ่ม | 5 | 1.00% | 1 ใน 100 คน |
| คลิกเกอร์ 3 ปุ่ม | 5 | 0.80% | 1 ใน 125 คน |
| กระเป๋า | 2 | 0.25% | 1 ใน 400 คน |
| แก้วน้ำ | 2 | 0.25% | 1 ใน 400 คน |
| ขอบคุณจ้า | — | ที่เหลือ | |

ถ้ามีคนเล่นประมาณ 800 คน รางวัลจะทยอยออกจนหมดพอดี ถ้าคาดว่าคนเยอะกว่านี้ ลด % ได้ใน Staff Console

### Staff Console
แตะโลโก้ **CAMT NEXTOPIA** มุมซ้ายบน 5 ครั้ง (หรือเปิด `/#staff`) แล้วใส่ PIN สตาฟ
(PIN ไม่ได้อยู่ในโค้ด เก็บเป็น hash ในฐานข้อมูล ใส่ผิดเกิน 20 ครั้งใน 5 นาทีจะถูกล็อกชั่วคราว)
- **ตรวจรหัสรับรางวัล**: พิมพ์รหัสที่น้องโชว์ ระบบบอกว่าจริง/ปลอม/รับไปแล้ว แล้วกด "มอบของแล้ว"
- ปรับสต็อก / % โอกาส / เปิด-ปิดรางวัล — มีผลกับทุกเครื่องทันที
- ดูสถิติ + ประวัติการหมุนทุกเครื่อง, ดาวน์โหลด CSV
- **โหมดบูธ**: ติ๊กบนแท็บเล็ตที่ตั้งให้หลายคนเล่น จะหมุนได้ 1 ครั้งต่อการเล่นจบ 1 รอบ
- **ล้างข้อมูลทั้งหมด**: กดก่อนเริ่มงานจริง เพื่อลบประวัติตอนทดสอบและคืนสต็อก

### ฐานข้อมูล
SQL ทั้งหมดอยู่ที่ `supabase/nextopia.sql` (ติดตั้งแล้ว) ตั้ง/เปลี่ยน PIN ด้วย SQL Editor:
```sql
update nextopia.settings set value = extensions.crypt('PIN_ใหม่', extensions.gen_salt('bf')) where key = 'pin';
```

## โครงสร้างไฟล์
```
index.html             หน้าเว็บทั้งหมด
css/style.css          ธีมนีออนเมืองอนาคต
js/config.js           URL + publishable key ของ Supabase
js/data.js             ข้อมูลสาขา + คำถาม (แก้คำถามได้ที่นี่)
js/icons.js            ชุดไอคอน SVG (ใช้ทั้งใน HTML และวาดลง canvas)
js/avatar.js           ตัวละครพิกเซล (ประกอบจากชิ้นส่วน)
js/city.js             เมืองพิกเซล 5 เขต + พลเมืองทุกคน
js/share.js            การ์ดแชร์ลงสตอรี่
js/wheel.js            วงล้อ + เรียก API รางวัล
js/app.js              ลำดับหน้าจอ, คิดคะแนน, Staff Console
supabase/nextopia.sql            ตาราง + ฟังก์ชันสุ่มรางวัล / Staff
supabase/nextopia_residents.sql  ตัวละคร (พลเมือง) ในเมือง
vercel.json                      proxy /api/rpc → Supabase
```
