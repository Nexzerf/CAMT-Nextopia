# CAMT Nextopia

เกมค้นหาสาขาที่ใช่ในวิทยาลัยศิลปะ สื่อ และเทคโนโลยี (CAMT) มช. สำหรับงานอบรม/แนะแนวตามโรงเรียน
งานอาร์ตและระบบตัวละครยกมาจาก **MMIT World** (`Nexzerf/MMITWorld`) ทั้งชุด

## ลำดับการเล่น
1. **หน้าแรก**: แนะนำเกม + ตัวละครตัวอย่างในชุดของ 5 สาขา
2. **สร้างตัวละคร**: ชื่อเล่น ทรงผม สีผม สีผิว เพศ (ตัวกรองชื่อหยาบแบบเดียวกับ MMIT World)
3. **ตอบ 6 คำถาม**: ตัวละครเดินไปตามทางสู่ธงเส้นชัย
4. **หน้าสรุป**: ระบบ**ลุ้นของรางวัลให้อัตโนมัติ** (ไม่ต้องหมุนวงล้อ) แสดงไว้บนสุด
   - ได้รางวัล → รูปของรางวัลขนาดใหญ่ + "แสดงหน้าจอนี้ให้พี่สตาฟดู"
   - ไม่ได้ → "ขอบคุณจ้า"
   - ตามด้วยสาขาที่ใช่ (ตัวละครใส่ชุดประจำสาขา) และข้อมูลจากเล่มหลักสูตรจริงของสาขานั้น:
     ชื่อปริญญา/หน่วยกิต/โครงสร้างหลักสูตร, เส้นทาง 4 ปี (รหัสวิชาจริงตามแผนการศึกษา),
     ปีสุดท้าย (WIL/สหกิจ), วิชาเลือกที่น่าสนใจ, อาชีพ, สาขารองลงมา และทำไมต้อง CAMT
   - ปุ่ม **แชร์ลงสตอรี่** (การ์ด 1080×1920)

| สาขา | ชุดตัวละคร |
|---|---|
| Software Engineering | ฮู้ดดี้ + แล็ปท็อป |
| Modern Management and IT | เชิ้ต + เน็กไท + แท็บเล็ต |
| Animation and Visual Effect | เสื้อสีสด + โทรโข่ง |
| Digital Game | ยูนิฟอร์ม + หูฟัง |
| Digital Industry Integration | ชุดช่าง + กล่องเครื่องมือ |

## ของรางวัล (ตั้งไว้สำหรับรอบละ ~100 คน)
สุ่มบนเซิร์ฟเวอร์ (Supabase) พร้อมตัดสต็อกในขั้นตอนเดียว ทุกเครื่องใช้สต็อกเดียวกัน ของหมดแล้วไม่แจกเกิน
มือถือ 1 เครื่องลุ้นได้ 1 ครั้ง (เล่นซ้ำได้ แต่ได้ผลรางวัลเดิม)

| รางวัล | จำนวน | โอกาส |
|---|---|---|
| คลิกเกอร์ 1 ปุ่ม | 5 | 4% |
| คลิกเกอร์ 3 ปุ่ม | 5 | 4% |
| กระเป๋า | 2 | 1.5% |
| แก้วน้ำ | 2 | 1.5% |

รวม ≈ 11% → ประมาณ 11 คนต่อ 100 คน (ปรับได้ที่หน้า Staff)

## หน้า Staff: `/staff/`
ใส่ PIN สตาฟ (เก็บเป็น hash ในฐานข้อมูล ไม่อยู่ในโค้ด)
- ปรับสต็อก / % โอกาส / เปิด-ปิดรางวัล (มีผลทุกเครื่องทันที)
- **เริ่มรอบโรงเรียนใหม่**: ล้างประวัติผู้เล่นและคืนสต็อกให้เต็ม (กดก่อนเริ่มแต่ละโรงเรียน)
- โหมดบูธ: ติ๊กบนแท็บเล็ตที่ให้หลายคนเล่นเครื่องเดียว (เล่นจบแต่ละคนได้ลุ้นคนละครั้ง)
- ประวัติผู้เล่น + ดาวน์โหลด CSV

## เทคนิค
- Next.js (static export) + Supabase (project `Project2`, schema `nextopia`)
- เว็บเรียก API ผ่าน `/api/rpc/*` บนโดเมนเดียวกัน (`vercel.json` ส่งต่อให้ Supabase)
  เครือข่ายโรงเรียนที่บล็อก `*.supabase.co` ก็ยังใช้ได้
- SQL อยู่ใน `supabase/` (ติดตั้งแล้ว)

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # ได้ไฟล์ static ใน out/
```

## โครงสร้าง
```
src/lib/majors.ts       ข้อมูล 5 สาขา + 6 คำถาม (แก้คำถามที่นี่)
src/lib/curriculum.ts   ข้อมูลหลักสูตรแต่ละสาขา (ปริญญา หน่วยกิต วิชาแต่ละปี วิชาเลือก WIL อาชีพ)
                        อ้างอิงเล่มโครงสร้างและแผนการศึกษา: SE 2568, MMIT 2565, ANI 2567, DG 2562, DII 2567
src/lib/scoring.ts      คิดคะแนนสาขา
src/lib/prize.ts        เรียก API ลุ้นรางวัล / staff
src/lib/sprite.ts       ตัวละคร pixel (จาก MMIT World)
src/lib/icons.ts        ไอคอน pixel 16×16 (จาก MMIT World + คลิกเกอร์/แก้วน้ำ)
src/lib/share.ts        การ์ดสตอรี่
src/components/play/    หน้าเกม (Intro / ProfileStep / QuizStep / ResultView)
src/components/staff/   หน้า Staff
```
